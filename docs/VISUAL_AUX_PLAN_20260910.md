# R2上的视觉辅助监督消融：预注册计划

用户已于2026-09-10授权执行C8分析提出的对照。目标首先是稳定提升macro IoU，其次才是机制创新。本计划在新训练和结果查看前冻结。

## 三组与初始化

- R2：既有无辅助监督基线，seed1219，训练SHA `9eca26de5b301099805530edbf5a1a8718bea662`。完整80轮、Val IoU选Best；历史结果只在源码兼容核验通过后复用。
- S1：R2＋四尺度像素BCE，有效系数0.02。
- S2：R2＋四尺度像素BCE/区域存在BCE/区域占比MSE，有效系数0.02/0.01/0.005。

从R2代码派生；保留C8视觉头的结构和目标定义，移除不连接视觉主干的文本辅助与无用推理路由。辅助头不改写主干特征。S1/S2辅助头创建使用独立、恢复状态的随机数上下文，保证共享主干初始权重及后续随机流相同；两组共同像素头初始化也相同。主模型现有文本通道保留、CXR-BERT冻结。新增头不载入C8训练权重，全部从头训练。

基线复用前检查：新代码中的R2必须与冻结原R2的共享状态、真实输入及五步预检输出/loss完全相同；候选须和R2具有相同共享初始化、首个主输出、数据/增强顺序及随机状态。若核验失败，先修复工程差异；不能静默复用不匹配的旧结果。短预检权重不进入正式训练。

## 固定配方

80轮单次余弦，首轮3e-4、末轮1e-6；Adam，weight decay1e-4，原EPPA保护参数分组；batch16、224、seed1219、4 workers、drop_last、原图像增强、原Dice/Focal各0.5。四尺度224/112/56/28；GT面积平均下采样，六个随增强变换的几何区域，不新增肺叶标注。无LoRA、boundary loss、新视觉预训练模型或文本辅助loss；不改阈值0.5与Val macro IoU选Best。

S1完整80轮完成后归档，再启动S2，不能因S1早期/最终数值改变S2配置或取消已注册对照。两组均独立源码提交、tag、manifest、工作树和运行目录。训练成功后自动导出完整1429张Val；本阶段不读取Test。最终性能仍以Test为准，在筛选和匹配种子复验后统一评估。

## 机制记录

在第20、40、60、80轮结束时，对按固定文件名哈希选出的32张Train图像记录eval模式特征梯度及FP/FN/面积偏差；批量8。此为训练程序内的预注册遥测，不是远程状态轮询。诊断前后恢复随机数、模型模式，不执行optimizer更新，不改变参数或BN状态；诊断失败应明确记录，不能污染训练。四尺度梯度均使用真实loss系数；不把梯度范数换算成IoU因果贡献。

## 阶段门与后续

分别对R2比较S1和S2：Val macro IoU差值至少+0.003，10000次配对图像bootstrap95%下界>0；总体Dice/Precision、最小GT总面积四分位Dice/Recall不降，Brier不升。所有条件冻结，不根据结果放宽；分层是总面积，不称作连通小病灶检出率。

S2独立区域价值还要求相对S1的IoU至少+0.001且95%下界>0，并满足相同非退化条件。S2只超过R2不能证明区域任务优于普通像素深监督。两组结果全部报告，未通过者不延长150轮或自动重调系数。

通过R2筛选的候选才补充2027/3407匹配种子，与已核验的同种子R2比较；每个候选两个种子都完成后再汇总，不能看到第一个结果再决定是否报告另一个。三种子IoU差值均>0，平均至少+0.003；平均Dice/Precision/最小面积Dice/Recall不降、Brier不升，才进入统一Test。若S1有效而S2没有额外价值，报告普通深监督收益，不能宣称区域监督创新。是否拆除S2中的存在/占比项由该增量门决定。

## 检查、存储与备份

每次训练最多两次短连接：约15分钟一次，用实测完整轮时预测结束；第二次约预测结束后12分钟，核实距真实结束≤30分钟。使用当前任务的定时预约，不保持SSH、不循环查询。若预测严重失准/训练异常，记录事实并说明，不能虚称满足时限。
