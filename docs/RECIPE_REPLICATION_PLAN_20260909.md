# R2 学习率配方：预注册的配对种子复验

前置筛选已完成：seed1219的R2对C4，Val macro IoU +0.0038572696，逐图配对95%区间[0.0005122746,0.0071447087]，Dice和最小病灶组IoU点估计均未下降。R1未通过，因此不组合R1增强，不延长到150轮，不新增模块/监督/loss。

按已经授权的2026-09-08实验计划继续：复用seed1219的完整C4/R2结果，补充 **2027、3407** 两个匹配种子。每个种子都重新训练C4与R2，均80轮、batch16、224、确定性CUDA、4 workers、drop_last、原Dice/Focal、Adam与weight decay 1e-4、原增强、原冻结文本编码器、无LoRA/外部视觉分支，从头训练。唯一组间干预仍为原10轮LR重启 vs 单次80轮余弦。所有超参数、阈值0.5和Val macro IoU选模规则均固定。

执行顺序：C4-2027 → R2-2027 → C4-3407 → R2-3407。每组独立manifest、完整来源SHA、实验tag、工作树和运行目录。该顺序不根据中间数值改变；2027没有通过单种子筛选也要完成已注册的3407配对，避免选择性报告。运行错误先排查并保留失败证据，不作为数值负结果。

源代码基于已验证的3c10d261e8509da4d96a97c183d75aa231427fd1，仅扩展manifest允许C4和预注册种子，并在预检输出中记录seed，不更改模型、数据变换、loss、优化器或调度器数学。C4沿用原profile，不伪装为新架构。每个种子的两组都做真实Train batch五步预检，要求配对初始权重、输入、五步输出和loss完全相同；正式训练不会载入这些临时权重。

## 预先固定的最终判断

1. 汇报3个种子各自的C4与R2 IoU/Dice、配对差值、差值均值和样本标准差，不能只报最优种子。
2. 三个种子的IoU增益均须>0，平均增益须≥0.003；平均Dice及平均最小GT面积四分位IoU差值也须≥0。原单种子的逐图bootstrap门槛继续作为每对描述，但不得要求2027先通过+0.003才运行3407。
3. 全部匹配训练完成且上述复验条件满足后，固定方法与checkpoint规则再进行Test；不能根据Test调整阈值、挑种子或再选epoch。最终成果以逐图macro Test结果为准，当前不能宣称已取得稳定Test增益。
4. 不满足则报告配方复验未通过，不自动追加种子、改变学习率下限、延长训练或组合R1。即使通过，训练配方优化也不作为第二项结构创新。

## 检查与存储

每次训练仍最多两次短连接检查：约15分钟后第一次，以完整轮时预测；第二次约预计结束后12分钟，核实真实间隔≤30分钟。每个run独立计数，不持续连接、不循环轮询。完成后自动完整Val导出，归档已完成静态文件不作为新增训练状态检查。
