# C4 训练配方实验计划（2026-09-08）

目标是先提高可复验的 IoU。训练配方优化本身不宣称为 Capstone 的第二项结构创新。

## 预注册的两组实验

| 项目 | R1：胸片方向增强 | R2：单次余弦衰减 |
|---|---|---|
| profile | r1_chest_augmentation | r2_single_cosine |
| 对照 | 已完成的 C4，80 epochs、seed 1219 | 同一 C4 |
| 唯一干预 | 删除原 50% 概率分支中的 90° 倍数旋转和镜像，变为恒等变换 | 原 10 轮余弦重启改为覆盖 80 轮的单次余弦 |
| 保留 | 原小角度旋转分支、两套随机数流、学习率重启 | 完整原增强、首轮学习率 |
| 学习率 | 原 3e-4 至 1e-4 的周期，T_0=10、T_mult=1 | 第 1 轮 3e-4，第 80 轮 1e-6，之后钳制在下限 |

共同条件：C4/FAM-EPPA 模型、冻结的原文本编码器、无 LoRA、原 Dice/Focal、Adam、weight decay 1e-4、224 输入、batch 16、drop_last、4 workers、seed 1219、确定性 CUDA、从头训练 80 轮。既有训练/验证划分和二值 GT 不变。验证集 macro IoU 选择 Best，固定阈值 0.5；不做阈值搜索。每组独立 commit、完整 SHA、实验 tag、manifest 和原始运行证据。

R1 保留被删除分支原有的 k/axis 随机数抽取，因此不会连带改变后续随机增强的抽样序列。仍有约 25% 的小角度旋转；不扩大其概率。R2 同时改变重启方式和后期 LR 范围，结论限定为“整个学习率配方有效”，不能把其收益单独归因于去掉重启。

## 执行与筛选

1. 先验证默认增强与冻结 C4 输出和随机数状态逐项一致，检查原调度器序列及新调度器 80 个 LR、端点与恢复。
2. GPU 预检使用真实 Train batch，确认无外部视觉分支、初始基础模型与 C4 一致。R2 与 C4 的输入和前 5 步输出/损失相同；R1 的独立两次预检相同。临时步骤不保存为正式训练初始权重。
3. 先训练 R1，完成后自动导出全部 1429 张 Val 的逐图指标。归档、筛选之后启动 R2，R2 不依赖 R1 成功。
4. 两组分别对比 C4：macro IoU 增益至少 0.003（0.30 个百分点）；10,000 次逐图配对 bootstrap 的 IoU 增益 95% 区间下界 >0；macro Dice 和最小 GT 面积四分位组的 IoU 点估计均不下降。Precision/Recall、FP/FN 用于诊断，不另行择优。
5. 单种子通过仅作为候选。通过者再与匹配 C4 在 seeds 1219/2027/3407 上复验，报告三个配对增益、均值和离散程度。三个 seed 均为正、平均 IoU 增益至少 0.003 才称为跨种子候选；逐图 bootstrap 不能替代种子稳定性证据。
6. 两组均通过才考虑组合，组合需单独注册和对照。若均失败，结束这条配方支线，按已有分层错误证据选择下一个假设，不能直接延长训练或新增模块碰运气。
7. 方法和选模规则固定后，正式候选执行 Test 评估；最终结论以逐图 macro Test IoU/Dice 为准。此阶段训练只自动导出 Val，不访问 Test。已有反复使用过的 Test 不能描述为从未见过的独立确认集；论文如需更强泛化主张，应增加新的独立数据证据。

## 检查次数与预计结束时间

每次正式训练最多两次短连接检查；发起后台进程仅返回 PID，不读取训练状态。第一次安排在启动约 15 分钟后，利用已完成整轮（Train+Val+保存）的用时估算剩余时间，排除第一轮初始化开销。第二次计划在预计训练结束约 12 分钟后，采集最终状态、完整 Val 和实际结束时间。随后核实结束至检查不超过 30 分钟。预测存在误差，不将其写成已保证的实际结果；若第二次发生时尚未结束，则如实报告并保留日志，不增加第三次状态检查。

不保持 SSH 连接、不设置循环轮询或完成监听器。定时任务读取本地检查预算，常规健康状态保持安静；完成、失败或需要处理的变化才通知。R1/R2 各自独立预算，R1 完成通知可同时说明 R2 已启动。

存储使用服务器系统盘的独立工作树和运行目录；共享 fs 必须低于 20,000,000,000 实际字节。保留原始数据、Best、来源与评估证据，训练结果按既有归档流程上传。当前计划不需要删除旧结果。
