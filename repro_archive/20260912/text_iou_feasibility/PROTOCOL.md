# E0/E1：修复分支塌缩之后的只读 Train 可行性审计

本次不训练、不修改任何模型或阈值。代码、manifest、固定样本名单先提交并标记；缓存与已完成 D 的 512 步 checkpoint 均核验哈希、只读复用。不访问旧 B holdout、官方 Val/Test，不写共享 fs。

## E0（1930 eligible fit）

在全部原 eligible fit 上，用逐像素 GT oracle 计算 ±0.5 logit 残差的最乐观二值 IoU：所有可去除 FP 去除，所有可补 FN 补齐。无空间/文字约束，故仅是上界，绝不是模型收益。另用 ±1.000001 的有效 logit 变化窗口给质量投影的宽松上界：delta∈[-.5,.5]、lambda∈[min(delta),max(delta)]，有效变化至多1；额外1e-6仅覆盖此阈值附近 float32 运算舍入。这个宽松集合不保证满足软质量约束，不能当作投影的可达精确最优。

报告每图基线与两个上界的 TP/FP/FN 和 IoU，靠近阈值的 FP/FN 比例，以及 eligible 均值增益乘1930/4585的全 fit 折算。不是官方 Val/Test 预测。若连宽松上界都小于0.003，停止当前冻结输出接口；否则继续 E1，但不视为通过方法门槛。

## E1（原32 + 固定新增128）

新增128由 sha256('text-e1-v1:'+文件名) 排序选择，与原32不重叠，不按结果筛选。它们仍属于 D 拟合集合，不能声称独立验证。

1. 冻结基线概率处，计算准确 R2 Dice/Focal 总目标及各分量的概率梯度；报告不受限 logit 梯度、质量投影切空间梯度，以及有/无投影时28×28双线性参数化的下降方向。系数梯度诱导全分辨率方向 h=W·(WᵀgW)·Wᵀ；有投影时再用 h−sum(w*h)/sum(w) 表示重新求lambda之后的实际有效logit方向，w=p(1-p)。在 FP/FN/TP/TN 及 |z|≤0.5 子集中分别数有害/零方向和梯度绝对量。各分量未加0.5，total为实际目标。空间梯度只检验此参数化，不代表训练头的完整参数梯度。
2. 固定 D AdamW 的全部六个头，不倒选 checkpoint。正确文字、关系交换文字，以及缓存已有、与canonical不同但语义等价的 source_text 控制。未缓存的同义句不新编码、不伪称完成；文本控制限定新增头，原 R2 主干文字保持原始正确输入。
3. 在同一批样本上报告 loss 与二值 IoU、FP/FN 变化、原错误被修复/原正确被破坏的数量。由原32逐图输出准确复现 D 作为执行验证。
4. 预定每图前5%像素预算：以 |p_head-p_base| 选位置，对比基线 p(1-p) 不确定性及 image/template 头，报告原错误覆盖精度；不按结果改变预算。只说明现有输出的错误定位能力，不证明文本信息理论上无用。

E1 失败只否定当前训练头提供新增纠错证据，不否定所有文字方法。任何新机制需区分文字信息、视觉可辨性、优化配方三项，先新的训练内协议，再完整匹配 Val 门、种子，最后 Test。不会自动延长至80/150轮，不用同一旧 holdout 反复调参。
