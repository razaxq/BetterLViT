# F：细尺度局部纠错接口，五折 Train 内筛选

本轮只验证接口，不声称文字创新。基于E的定位/空间冲突诊断，用户已授权执行。源代码、split和manifest在预检/拟合前提交并标记；不改R2、EPPA或任何历史实验。

## 数据与划分

只使用原B的4585张fit，原1131 holdout继续关闭；不读取官方Val/Test图像或mask。按原group_id用sha256('local-f-v1:'+group_id)%5固定五折，能识别sub-S患者ID者同组，其他按文件名分组，不能宣称全部患者独立。每折新增头只拟合另外四折，最后一步对自身留出折评估一次，合并4585个OOF预测。R2曾训练过全部原Train，本轮仍是开发筛选，绝不是独立泛化/Test结论。

缓存重用B原logits、packed masks、28×28特征。仅新增每图1024个候选点的原up1细尺度64通道特征fp16及uint16点索引，精确610355200字节；启动须实际剩余空间≥缓存+256000000字节。shared fs不写，不复制或删除B缓存。候选点由固定R2的p(1-p)排序，平局按像素索引，不用GT或文字分数选点；1024是本轮事先固定预算，不把E的5%统计转为调参依据。

用冻结R2重新提取细特征时，按旧B原物理batch边界处理，仅加载fit图像，缺少的批内成员重复同批fit样本补齐原batch大小，不加载旧holdout。逐图验证logits、28池化fp16特征、mask、原文字身份与B缓存精确一致；不放宽容差。模型前后state hash一致。文本元数据/文件名可作身份核验，任何旧holdout图像/mask不进入推理或训练。

## 四组共同配置

新增头无额外文字输入，原R2特征仍含原始正确文字。相同MLP形状：归一化64维视觉特征、clamp(z,-8,8)/8、二维坐标，共67维；Linear67→128→64→1，GELU，输出层零初始化，残差0.5*tanh。相同初始权重、候选集合、训练顺序、2048步/折、batch16、AdamW 1e-3→1e-5单次余弦、weight_decay1e-4、clip5、原R2 Dice/Focal，无LoRA、boundary或新辅助loss。五折初始seed1219相同，折内采样器seed1219+fold。

| 组 | 修正接口 | 质量约束 |
|---|---|---|
| coarse_free | B的28×28特征+28池化logit，网格MLP输出后固定双线性插值，仅取共同候选点 | 无 |
| coarse_mass | 同上 | 仅候选点内保留原软概率总量 |
| fine_free | 直接读取原224×224 up1在候选点的特征与原logit，逐点MLP | 无 |
| fine_mass | 同上 | 仅候选点内保留原软概率总量 |

所有候选点外的概率逐位不变；保量只在候选内求lambda，故全图软量也保留，但不保证硬面积/IoU。该局部投影沿用已验证隐式梯度，其位置范围不同于B/D全图投影，本轮四组用于内部受控对比，不与旧T4直接归因。粗/细接口同时改变可读细节和输出空间耦合；不能把差异全归因于一个“分辨率”变量。

## 预检、最终评估与门

CPU/CUDA合成预检：零初始化identity、点外严格不变、候选唯一、质量误差≤0.02、隐式投影gradcheck、插值一致、参数/梯度有限、确定性前反向。真实fit batch只用于可训练性/速度预检，预检头全部丢弃；正式各折重新初始化。测量共同四头步时、评估步时与缓存耗时形成ETA，禁止靠持续SSH等待训练。

每折2048步是固定最终checkpoint，512/1024/1536仅保存可恢复状态和数值日志，不评留出折、不择优早停。每折完成自动评其留出折一次，保存全部逐图TP/FP/FN/Dice/IoU/Precision/Recall/Brier，修好原错/破坏原对的转移与软量误差、候选外不变校验。小病灶阈值各自由该折拟合集合的GT面积25%分位取得；留出GT不参与阈值计算。

预注册基础接口门：OOF相对R2 macro IoU≥+0.001、按group bootstrap区间下界>0、至少4/5折IoU正向；总体Dice/Precision、各折训练阈值定义的小病灶Dice/Recall不降，Brier不升。四组均完整报告。细接口另需超过对应粗接口，配对group区间下界>0。bootstrap10000次、seed1219；多重比较未校正，只作开发筛选。若多个细接口通过，按OOF IoU较高者推进文字对照，相同则fine_free优先；不改配置重复旧折。

通过只支持进入第二步文字增量研究，不自动开80轮/Test。若仅粗接口通过，保留结果并重新定位，不把细接口假设判成功。若所有门失败，封存并诊断，不延长训练或挑某折。后续完整80轮、Val+0.003及匹配种子/Test门保持。

## 执行与存档

预检/缓存与正式训练分开。预检完成后按实测预测正式训练的完成时间，提交后台并断开SSH；同一个原生heartbeat安排最多两次检查。首检若已完成即关闭；否则按运行写入的ETA安排唯一末检，目标结束后30分钟内，不循环轮询。完成后下载结果和20个折内头，逐文件SHA与本地独立复算；代码/负结果/日志推送GitHub，完成结果按源短SHA备份HF。
