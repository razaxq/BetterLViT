# 第二创新点：下一步计划与执行入口

目标是找到能与 EPPA 配合、可单独验证的结构贡献。目前第二创新点尚未成立。

## 这次验证什么

候选机制是**文字引导的视觉特征分组与回传**：文字决定哪些图像位置参与同一组，
模块先从图像汇集组特征，再把组特征传回图像位置，并减去本位置的投影特征形成残差。
新增分支的值向量全部来自图像。原 LViT 和 EPPA 的文字路径照常工作。

直观流程：

`图像位置 + 文字锚点 → 分组权重 → 汇集图像特征 → 回传到图像位置 → 形成视觉残差`

EPPA 已有的频率分解、细节融合保持不变；新分支放在 up3 后、up2 前，验证跨位置的
全局信息交换是否有帮助。这个解释只是待验证的机制假说，不代表已证明语义定位正确。

先前 T2 的文字直接参与值向量。T2 干预显示文字分支有用，已有位置绑定敏感性；
关闭分支没有改善小病灶。因此旧的短语/拒配路线入口条件失败，本次另外登记新假说。

## 两组匹配实验

| 项目 | M1 视觉对照 | M2 文字候选 |
|---|---|---|
| 分组锚点 | 池化后的32个图像区域 | 现有32个文字状态，屏蔽padding |
| 被聚合的特征值 | 图像 | 图像 |
| 新增参数 | 16,896 | 16,896 |
| 初始化 | 相同，初始残差为0 | 相同，初始残差为0 |
| 训练 | 从头80轮，seed1219，batch16 | 从头80轮，seed1219，batch16 |

两组均固定 EPPA V4-B、冻结 CXR-BERT、无 LoRA、Dice/Focal、boundary loss=0，
沿用 R2 的优化器、增强及单次余弦学习率。基线复用 R2，不采用阈值调整后的分数。

## 执行顺序

1. 完成行为检查和真实 Train 批次 GPU 预检，核对初始化、梯度和观察日志不干扰训练。
2. 冻结独立源码 SHA 与实验标签；核验云端备份后释放历史 Last 副本占用的空间。
3. 训练 M1，成功后自动评估 Best 的完整 Val，核验并归档；随后训练 M2。
   M1 排名不佳也不取消 M2。每组约15分钟首检一次，再预约一次预测末检。
4. 比较 M2-R2 与 M2-M1。通过事先判据后，才进入额外种子、机制消融和论文差异化论证。

## 怎样判断是否值得继续

- M2 相对 R2 的逐图 macro IoU 至少提升 **0.30个百分点**，分组描述性95%区间下限大于0。
- M2 相对 M1 的 macro IoU 为正，分组描述性95%区间下限大于0。
- M2 的 macro Dice、最小病灶四分位 macro IoU 对 R2 和 M1 都不退化。
- 来源、实际学习率、Best 选择和完整 Val 导出核验通过。同步报告 Precision、Recall、Brier、FP/FN。

筛选只用 Val，固定严格概率>0.5，不新增 Test 访问。单种子通过只说明值得继续。
如果 M1、M2 都提升而 M2 不胜 M1，证据支持视觉聚合，不能把收益归因于文字。
如果不通过，就关闭这个版本，不事后降低门槛。

类似的像素—区域—像素聚合已有 [OCR](https://arxiv.org/abs/1909.11065)，
医学分割的语言条件重建也有 [RecLMIS](https://arxiv.org/abs/2404.02845)。因此不能把
注意力、原型聚合或“使用文字”本身认领为创新。最终需要证明具体机制的必要性、与
EPPA 的互补性、跨种子的稳定收益，以及与已有方法的实质区别。
