# 第二创新点候选复核：允许不匹配的短语—区域交互

2026-09-13。状态：研究候选，未实现模型模块，未启动训练，未新增 Val/Test 评估。查新不是穷尽检索，不认领首创或已成立的第二创新点。

## 选择依据

当前建议集中验证：**面向不完整医学描述的可拒配短语—区域交互**。完整短语与局部图像建立允许缺省、允许不等覆盖范围的对应，只用获得图像支持的对应修改解码特征。创新假说落在医学描述的对应规则及推理机制；普通短语池化、空匹配或最优传输本身均有先例。

现有配对实验表明普通文字注意力 T2 相对 R2，Val macro IoU -0.1990 pp，最小病灶组 -1.0053 pp；全体 FP 增加 54,616 像素、TP 增加 15,685 像素。这是过分割倾向的证据，不证明 softmax 或文字内容就是原因。原文与数值见 ../text_decoder_controls/COMPLETE_REPORT.md。T1 视觉分支也退步，因此新增结构/优化干扰仍是竞争解释。

此前 Train 文本静态审计发现相同词袋但位置绑定不同的 36 组、1,236 个样本，支持检查完整短语是否必要。不能从这些静态统计推断已有模型不懂词序。

当前本地迁移副本的 5,716 张 Train PNG 全部 224×224，见 png_size_audit.json。故放弃“裁剪原始高分辨率可恢复更多细节”的论据；该审计不证明远端或未收集的原始数据不存在更高分辨率。既往局部修正筛选也没有支持细分辨率接口的有效收益。

## 候选机制与边界

1. 将带修饰关系的完整描述，如“左下肺病灶”，从现有冻结 CXR-BERT token 中按可追溯 span 聚合。先核对现有长度卷积，避免在 token 位置已混合的特征上错误套用 span。严格解析失败时走已定义回退。
2. 由局部视觉特征与短语内容计算对应。与所有位置都分配完整文字权重的注意力比较，允许位置的总匹配权重小于 1；剩余权重表示本次不做文字修正。短语可对应多个位置，也可无有效对应；不同短语的覆盖规模不由字数或出现次数决定。
3. 最小实现先比较“普通短语注意力”和“加入空匹配的短语注意力”。只有后者显示作用，再研究带软边际约束的非平衡匹配，避免把复杂求解器当成创新。区域匹配总量与整张预测的前景面积不是同一个量；不重做此前全局面积守恒的 TER 输出修正。
4. 匹配权重必须保留到残差幅度：若匹配行和为 m_i，修正写作 alpha * sum_j(P_ij * value_j)，不能除以 m_i 后丢掉拒配作用。没有有效对应时新增残差为零，保留原 R2/EPPA 路径；未提及区域仍可由原路径预测，不能当成背景标签。
5. 最初只使用原有分割主损失，不添加区域伪标签损失。机制在推理时使用真实文字，单次视觉主干与单次文本编码；新增参数、时延、显存必须实现后实测。软匹配拒绝全部文字仍可能塌陷，必须监控，不能强行铺满区域来避免塌陷。

这里的主要假说是：保持描述的关系结构，并限制无证据的文字干预，可以减少小病灶误检。它未获因果验证，也不能保证改善 R2。

## 最小实验顺序与停止规则

1. **先做已规划的 T2 干预诊断**：固定 checkpoint，新增分支关闭/真实报告/同长度错配报告；原有文字通路一直用真实报告。不用错配制造新 mask，不选阈值。若关闭分支不能缓解小病灶损害，需重新审视优化和结构原因，不直接投入本候选。
2. **冻结接口再做工程预检**：span 对齐、空描述/解析失败、零残差恒等、有限梯度、确定性、预算实测。原增强包含图像翻转/旋转；不能直接把文字方位固定映射到图像坐标，若引入坐标必须正确传播同一空间变换，且单列对照。
3. **最小训练筛选**：同 R2 的 80 轮单次余弦、batch16、seed1219、固定0.5；依次比较完整短语注意力与完整短语+空匹配。共享相同接口、初始化和参数规模。R2/T1/T2 是历史锚点，但接口变化后不能省略新的严格匹配对照。先不训练复杂 UOT 版本。
4. **仅有前景时扩展**：若简单拒配通过门槛，再比较标准匹配与软边际匹配，同时做参数匹配视觉控制和真实文字/固定代码控制。错配导致下降本身不证明语义有效，必须真实文字优于可学习的模板代码。
5. **推进门槛（拟议，运行前登记）**：Val macro IoU 相对 R2 至少 +0.30 pp，最小病灶组 IoU/Recall 不下降，Precision/Dice 不下降；再进行至少3个配对种子并报告每种子差值与不确定性。单种子轻微升高或仅阈值改动不算通过。
6. 最终模型和全部选择只用 Train/Val 冻结后，在同一 Test 协议报告 macro IoU/Dice、precision/recall 和开销。已有 Test 被反复使用过，必须披露研究过程；本计划不把它变成新的独立保留集。0.54 工程阈值结果与0.5架构消融分别报告。

新的正式运行前需独立源码提交、40位SHA与实验tag、存储预检和可恢复的预测检查计划。本文件不创建训练进程或自动化。若两组最小筛选失败，停止该路线，不追加温度/损失权重的大范围搜索。
