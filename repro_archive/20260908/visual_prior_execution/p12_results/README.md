IoU退化主要来自较小病灶，较大两组近乎持平。1429例中640例提高、788例下降、1例持平。

像素总数仅用于错误诊断，不作为论文主指标：P12相对C4增加33,961个真阳性，同时增加58,440个假阳性，预测前景总数增加92,401。结合macro precision下降、recall小幅上升且其区间跨0，表现与预测范围偏大相符。没有可视化掩码或接入消融，不能据此确诊具体结构原因。

完整日志显示训练继续收敛，而Val收益有限：epoch20/40/60/70的Val IoU约0.7114/0.7145/0.7152/0.7168，epoch80回到0.7147。同期Train IoU从0.7083升至0.7466。该趋势不足以支持继续加长此配置；Train增强视图与Val固定视图不同，也不能只凭两者差距定性为过拟合。

CXformer胜过DINOv2的固定特征读出探针仍是成立的诊断结果，但它没有证明特征对C4有额外价值。本次淘汰的是这套普通中层相加配置；不将失败泛化成所有视觉预训练方法无效，也不将探针优势写成完整BetterLViT增益。
