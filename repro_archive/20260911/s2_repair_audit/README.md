# S2修复依据：先统一区域标签，再检验聚合方式

本轮是用户询问“S2的问题如何解决？”后的只读训练集审计和修正原型。未启动分割训练、未加载模型权重、未访问Val或Test图像；历史S1/S2成绩和冻结源码保持原样。审计使用S2源码 `7defc637e36974fabd0f47763275c90f617e5f53`，诊断源码提交 `00a9c1bddb9a5c7b3ab0c8df6612c5758ac56f7d`；脚本SHA和环境版本在[target_audit.json](target_audit.json)。

## 已确认的目标不一致

S2当前先平均池化mask，再和最近邻缩放的区域图相乘，最后由区域面积>0生成存在标签。平均池化与裁切区域不交换；区域边界穿过粗网格时，病灶像素可被归给邻区。应由增强后的224×224 mask和同分辨率、同几何变换的区域图直接计算一次区域存在/占比标签，各尺度共享。

对5716张Train图像，完全复现原读取/224缩放/二值化；统计六区域，共34296个区域标签：

| 尺度 | 与原分辨率不一致的标签 | 原本有病灶却变为无 | 原本无病灶却变为有 | 涉及图像 |
|---|---:|---:|---:|---:|
| 224 | 0 | 0 | 0 | 0 |
| 112 | 165 | 154 | 11 | 163 |
| 56 | 633 | 476 | 157 | 601 |
| 28 | 877 | 482 | 395 | 808 |

28尺度影响2.5571%的区域、14.1358%的图像。额外对每张图作一次固定随机种子的legacy几何增强，28尺度仍有835个不一致标签、涉及776张图像。这个增强抽样不是80轮真实数据流；不能将结果外推成训练全过程的标签错误率。这里指派生目标跨尺度不一致，不是原始标注错误。

已经提供`full_resolution_region_targets()`修正原型，直接用原分辨率mask与同步变换区域图计算foreground mass、presence、area和valid。它不读取文本、预测图或测试标签。四项CPU检查通过：单像素区域边界、旋转几何一致、空/无效/全前景、分辨率不匹配拒绝。单像素边界例子复现旧28尺度将中区病灶判到上区，修正后恢复正确区域。原型尚未接入新的正式模型，也没有修复后IoU结果。

## 区域平均特征可能削弱局部证据，但尚非因果结论

当前presence为`Linear(mean_region(feature))`，区域内直接特征梯度在空间上均匀分配。目标却是“任意位置有病灶”。Train阳性区域中1910个病灶面积不足区域的1%，5316个不足5%；均值汇聚提供的监督位置很粗。这是值得检验的建模风险，并不意味着平均池化在数学上不能学习存在任务，也不能证明它独自造成S2下降。

现有20/40/60/80轮、每轮32张Train的特征梯度快照中，presence的64个批次×尺度观察有20个与主loss负余弦；occupancy为0/64，合计visual auxiliary为1/64。presence加权梯度范数约主任务0.31%–2.64%，occupancy约0.012%–0.095%。这些是局部特征梯度，观察之间并不独立；不能称全参数训练梯度统计，也不支持“辅助梯度整体过大”的断言。占比项不能仅因范数小就判定无害。

## 推荐修复顺序

1. **第一候选只修区域目标，暂称S2-T。** 在目标模块携带原分辨率变换后的区域图，四尺度共享上述presence/area；像素BCE仍用现有面积下采样。保留S2原聚合方式、0.02/0.01/0.005系数、seed1219、80轮单次余弦与固定阈值。先做初始化/真实批次/标签回归检查，再做一组从头训练，和已冻结S2对照，区分工程修复与结构改动。最终是否继续仍须相对R2达到原IoU及非退化条件；历史S2失败结论不变。
2. **若目标修复后仍损失小面积召回，再隔离presence与occupancy。** 在一致标签上比较像素+presence和像素+occupancy；不能同时修改权重、层数、训练时机和池化后再宣称找到了原因。若Train上的轻量可学习性/梯度诊断不支持任务价值，就不投入完整80轮。
3. **presence确实是问题时，才验证局部证据汇聚。** 使用逐位置presence分数和固定的平滑max或注意力汇聚，与同参数/同标签的均值汇聚对照；不用GT直接选择推理区域。MIL为这类存在任务提供已有方法依据，但这些池化方法本身不是新创新。需证明额外IoU收益并恢复小面积组召回，才能继续谈机制贡献。

暂不优先延长训练、扫loss权重或直接上PCGrad。PCGrad针对冲突梯度，当前证据是presence部分局部冲突而合成辅助梯度多数不冲突；先修目标更容易解释。任何后续候选必须独立来源SHA/tag与预注册，不改历史模型。本轮仅诊断及原型，不自动恢复定时或启动训练；不能承诺标签修复必然提高IoU。
