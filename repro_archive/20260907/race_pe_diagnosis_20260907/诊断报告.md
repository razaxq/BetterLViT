# RACE-PE V1 退化诊断

2026-09-07。诊断范围：5716张训练图像的标签/区域审计、1429张验证图像的前向干预，以及16张验证图像的梯度探针。本次未重训、未访问Test。历史Test已按用户要求评估，不改变这一事实。

使用P9 validation-best epoch69，源码提交`8129c1f039ed77f78e70305aca0bb9708b3b56b1`。原模型完整验证集IoU精确复现已有结果0.7243345893510442。

## 1. 确认：文本存在性头的监督允许全阳性解

训练集六区监督共34296个位置：7894个正例、0个负例、26402个未知；1686张图像没有可解析位置。
`race_semantics.py:94`将标签初始化为-1，只向明确位置写入1；`race_pe_objective.py:31`只在已知位置计算BCE。

这使区域文本损失成为正例上的`-log(sigmoid(z))`平均值。每个受监督logit的梯度均为`(sigmoid(z)-1)/N_positive`，其单独的最优方向是全部增大；未知位置没有约束。将unknown排除出BCE是必要的，但单独这样做没有构成一个能区分存在/不存在的学习目标。这是本版设计缺陷，不是已经通过的数值预检能够排除的问题。

验证集8574个位置概率全部>0.99，均值0.998706，最小值0.992052；已知正例均值0.999388，未知位置均值0.998500。训练历史的末验证batch槽均值：epoch1=0.905853、epoch5=0.981653、epoch20=0.993586、epoch69=0.998699。退化从早期就持续发生。

## 2. 确认：该新增文本分支已经基本失去条件作用

只修改RACE槽头输出，保留主LViT/EPPA文本路径。全部实验均为同一个P9检查点的验证前向干预：

| 模式 | macro IoU | Precision | Recall |
|---|---:|---:|---:|
| P9原模型 | 0.724335 | 0.796023 | 0.889474 |
| RACE文本槽全部设为1 | 0.724333 | 0.796023 | 0.889472 |
| 批内循环打乱RACE文本槽 | 0.724333 | 0.796021 | 0.889475 |
| 关闭全部RACE残差路由 | 0.724149 | 0.802177 | 0.881141 |
| C4独立训练对照，供参照 | 0.722796 | 0.814701 | 0.864661 |

在全部71701504个验证像素中，全1干预仅改变20个二值预测，打乱槽仅改变16个。打乱是每个batch内循环移位；未打乱主网络文本，也未用mask生成替代文本。

当文本槽`t≈1`时，`agreement=1-|presence-t|≈presence`，原门控近似成为`presence×extent`。它退化为视觉增强分支，无法支持当前“图文一致性路由有效”的机制主张；不意味着整个BetterLViT不再使用文本。

## 3. 确认：区域监督存在几何与语义冲突

训练集在无增强、224×224的当前几何约定下，7894个报告派生正区域中，1522个区域的mask占比为0，冲突率19.28%。
例如`covid_1049.png`报告描述左右下肺病灶，但mask在当前左右下三分之一矩形中均为空、病灶主要位于中部矩形。这证明当前矩形区域对应存在问题，不能据此说医学报告或mask本身错误：图像等分区不是肺部解剖分区。

`race_pe_objective.py:49`对空mask区域监督presence=0，但`:56`的positive-only consistency仍对报告正区域监督presence趋向1。两个目标在这些区域上方向相反。上面的19.28%是训练集增强前、最高分辨率审计；不冒充所有增强批次的冲突率。

验证四个尺度的视觉presence也失去有效区分：真实区域阳性率约65%，预测区域阳性率约91%–100%。在真实空区域中，误判阳性的比例分别为99.02%、98.15%、88.06%、77.61%（阈值0.5）。验证正文本区域与mask的冲突率约21.9%–24.9%，随尺度变化。

Extent分支有一定区分能力：四尺度foreground加权均值约0.234/0.388/0.569/0.697，background加权均值约0.100/0.083/0.071/0.068。粗尺度使用soft area目标，不能把这些加权均值视为硬像素分类准确率。存在性与范围在实现上拆开了，但存在性监督没有因此变得可靠。

## 4. 可确定和仍不能确定的归因

关闭推理路由使precision提升0.615个百分点，平均每张FP由1013.63降至962.06，同时recall下降0.833个百分点；IoU仅下降0.0185个百分点。路由对当前模型有扩张预测范围的作用，其IoU边际收益很小。

关闭路由后precision仍比C4低1.252个百分点。说明单纯关掉推理路由不能恢复C4行为；它不能单独区分辅助监督与路由在训练期间各自造成的变化。这里没有将推理消融冒充重训消融。

4个batch、每batch4张验证图像的首层卷积梯度探针：辅助/主损失梯度范数比约0.063–0.176，余弦相似度为-0.260、0.149、0.541、-0.139。存在局部梯度冲突线索，但样本很少，不能证明辅助损失普遍支配主训练，也不能用它决定最终损失权重。

## 5. 修复优先级

1. 先修复文本目标的可辨识性。可将头定义为“报告是否明确提及该区域”，而不是“该区域是否实际有病灶”。未提及可作为提及任务的0，但必须与疾病不存在区分；含糊/不可解析描述仍需遮罩。保留视觉主干路径，不把未提及当成病灶负标签。
2. 在可靠区域对齐建立之前，移除或严格屏蔽与训练mask冲突的报告→固定矩形presence强制一致性。不要直接将整幅图三等分称为肺上/中/下区，也不要用推理时的GT病灶mask生成区域。
3. 最小消融应分离“修复文本目标”“移除冲突一致性”“只有像素辅助监督”。C6/C7尚未运行，不能预先声称哪一项会带来增益。建议先做可学习性小实验：正确/打乱文本输出应有可测差异、全阳性应被训练目标惩罚，再考虑完整配对。
4. 保留当前结果为失败版本；后续选型依据仍使用训练/验证。诊断本身不支持直接加长训练、扩大模块或承诺IoU增益。
